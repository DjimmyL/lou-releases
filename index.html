Comment l'installer ?How do I install it?
  1. AppImage : clic droit sur le fichier → Propriétés → « Autoriser l'exécution », puis ouvre-le. Dans un terminal : chmod +x Lou-linux.AppImage && ./Lou-linux.AppImage. Si elle refuse de démarrer : sudo apt install fuse3, ou prends le .deb.AppImage: right-click the file → Properties → "Allow executing file as program", then open it. In a terminal: chmod +x Lou-linux.AppImage && ./Lou-linux.AppImage. If it won't start: sudo apt install fuse3, or use the .deb.
  2. .deb : sudo apt install ./Lou-linux.deb, puis lance Lou depuis tes applications..deb: sudo apt install ./Lou-linux.deb, then open Lou from your applications.

Lou vit dans la zone des icônes de ton bureau. Sur GNOME, si tu ne vois pas son icône, active l'extension « AppIndicator » (déjà présente sur Ubuntu).Lou lives in your desktop's system tray. On GNOME, if you can't see her icon, turn on the AppIndicator extension (Ubuntu already has it).

Avec l'AppImage, les mises à jour se font depuis Lou en un clic. Avec le .deb, Lou te prévient et ouvre cette page.With the AppImage, Lou updates in one click, right from the app. With the .deb, Lou tells you when a new version is out and opens this page.
