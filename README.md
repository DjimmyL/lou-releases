## Installer sur Mac (recommandé, sans alerte de macOS)

1. Appuie sur **⌘ + Espace**, tape **Terminal**, puis **Entrée**.
2. Colle cette ligne, puis appuie sur **Entrée** :

```bash
curl -fsSL https://getlou.app/install.sh | bash
```

La commande choisit la bonne version pour ton Mac (puce Apple ou Intel), vérifie que le fichier téléchargé est intact, installe Lou dans **Applications** et l'ouvre. Tu peux [lire le script](install.sh) avant de le lancer.

## Ou télécharger l'app pour Mac

| Ton Mac | Téléchargement |
|---|---|
| Puce Apple (M1, M2, M3, M4) | **[Lou pour Mac Apple Silicon (.dmg)](https://github.com/DjimmyL/lou-releases/releases/latest/download/Lou-mac-apple-silicon.dmg)** |
| Processeur Intel | **[Lou pour Mac Intel (.dmg)](https://github.com/DjimmyL/lou-releases/releases/latest/download/Lou-mac-intel.dmg)** |

Ces liens donnent toujours la version la plus récente. Pour savoir quel Mac tu as : menu  → « À propos de ce Mac » → ligne « Puce » ou « Processeur ».

Ouvre le `.dmg` et glisse **Lou** dans **Applications**. Au premier lancement, macOS bloque Lou, car elle est gratuite et n'est pas enregistrée auprès d'Apple. Une seule fois : clique **Terminé** (surtout pas « Placer dans la corbeille »), puis va dans **Réglages Système → Confidentialité et sécurité** et clique **Ouvrir quand même**.

## Windows

**[Lou pour Windows (Lou-windows-setup.exe)](https://github.com/DjimmyL/lou-releases/releases/latest/download/Lou-windows-setup.exe)** — Windows 10 et 11, installation pour ta session, sans droits administrateur.

Si Windows affiche « Windows a protégé votre ordinateur », clique **Informations complémentaires** puis **Exécuter quand même** (Lou est gratuite et n'est pas signée par un éditeur payant). Lou apparaît en bas à droite, près de l'horloge.

## Linux

| Format | Téléchargement |
|---|---|
| AppImage (toutes distributions, se met à jour) | **[Lou-linux.AppImage](https://github.com/DjimmyL/lou-releases/releases/latest/download/Lou-linux.AppImage)** |
| Debian / Ubuntu / Mint | **[Lou-linux.deb](https://github.com/DjimmyL/lou-releases/releases/latest/download/Lou-linux.deb)** |

AppImage : `chmod +x Lou-linux.AppImage && ./Lou-linux.AppImage` (si elle refuse de démarrer : `sudo apt install fuse3`, ou prends le .deb). Paquet : `sudo apt install ./Lou-linux.deb`. ## Mises à jour

Ensuite, Lou se met à jour toute seule : elle te prévient quand une nouvelle version existe, et tu l'installes en un clic depuis ses réglages.

Lou fonctionne entièrement sur ton ordinateur : la caméra, la détection et ce qu'elle apprend de tes gestes ne quittent jamais ton ordinateur. Aucune image n'est enregistrée. La seule connexion à Internet est la recherche de mises à jour sur cette page GitHub, sans rien envoyer d'autre.

curl -fsSL https://getlou.app/install.sh | bash

## Updates

After that, Lou keeps herself up to date. She tells you when a new version is out, and you install it in one click from her settings.

## Privacy

Everything stays on your machine, nothing is sent over the internet. The camera, the detection and what Lou learns from your gestures never leave your computer, and no image is saved. The only time Lou goes online is to check this GitHub page for updates, and it sends nothing else.
